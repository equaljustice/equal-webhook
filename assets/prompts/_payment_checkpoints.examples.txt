📌 PAYMENT_CHECKPOINTS (USE-CASE CONFIG — copy and fill; amounts/when vary)
Trigger ONLY these checkpoints. Use the shared Payment Engine in `_common_control_protocol.txt`.

Format (keep ids stable; edit when/amount/unlocks/message per product):

PAYMENT_CHECKPOINTS:
  - id: <stable_id>
    when: <exact condition from this use-case>
    amount_inr: <number or null if message embeds amount>
    message: "<user-facing payment line in English; translate to chat language at runtime>"
    unlocks: <what to do after webhook Payment completed>
    once: true|false
